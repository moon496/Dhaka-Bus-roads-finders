# Dhaka Bus Route Finder - Frontend

React 19 + Vite commuter and administrator interface. The client uses the Node API for transfer planning, stop browsing, reports and administration. If the API is unavailable, it falls back to bundled data for direct-route search only.

## Commands

```powershell
npm install
npm run dev
npm run build
npm run preview
```

The Vite dev server proxies `/api` to `http://localhost:3001`; run the backend alongside it. See the root [README](../README.md), [User Manual](../docs/User_Manual.md), and [Installation Guide](../docs/Installation_Guide.md).
